# fitness-subscription-analytics

## Project Overview
This project analyzes fitness subscription data using Tableau to understand customer retention, revenue trends, and customer acquisition costs.

## Tools Used
- Tableau
- Excel
- GitHub

## Analysis
- Customer cohort analysis
- Revenue forecasting
- Customer Acquisition Cost (CAC) vs. Lifetime Value (LTV)
- Data model and relationships

## Project Files
The screenshots folder contains visualizations from the Tableau analysis.
